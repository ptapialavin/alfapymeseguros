Cómo funciona

  1. 1. Edita los campos que quieras cambiar más abajo (fotos, links de cada compañía, textos de portada, WhatsApp, etc).
  2. 2. Vista previa: abre el sitio en una pestaña nueva mostrando tus cambios, solo en este navegador — nadie más los ve todavía.
  3. 3. Descargar content.json: guarda el archivo actualizado en tu computador.
  4. 4. Publicar: reemplaza el archivo content.json en tu repositorio (arrastrándolo en la web de GitHub o con git add / commit / push) para que los cambios se vean en el sitio real.
